Privacy boundary

Private is a route, not a slogan.

The app distinguishes local processing from optional remote processing and never silently turns a local failure into an upload.

01 // LOCAL PRIVATE AI

Your default processing route

After verified models are installed, transcription and optional summaries run on the Mac. Local meeting content is not sent to Matthew Rogers.

02 // DIARIZATION

Separate voices, honest labels

MOSS labels turns as SPEAKER_01, SPEAKER_02, and so on. It does not perform biometric identification or pretend to know a real name.

03 // ADVANCED REMOTE

Explicit opt-in only

Remote processing sends content only to an endpoint you configure, enable, and confirm. It is not an automatic fallback.

04 // PURGE

A real delete boundary

Purge removes meetings, recordings, isolated tracks, transcripts, summaries, sidecars, orphaned files, and database records while retaining models and preferences.

Meeting flow

Capture. Understand. Keep control.

STEP_01

Capture both sides

Record system audio and the actual microphone selected for capture. Screen pixels are not written to disk.

STEP_02

Diarize locally

Create a timestamped, speaker-aware transcript with pinned, verified local model files.

STEP_03

Review or purge

Read the transcript, generate a local summary, copy clean Markdown notes, or remove the meeting data.
